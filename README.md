# minecraft-logs-viewer

用于在单个窗口中浏览、搜索和编辑 Minecraft 日志副本的本地桌面工具。

应用代码使用 Rust，界面使用 FLTK。支持 Windows、macOS 和 Linux，每个平台发行包小于 15 MB，优先控制在 10 MB 以内。

## 功能范围

- 浏览普通日志、实时日志和压缩归档中的日志。
- 支持 LOG、GZIP、TAR、ZIP、RAR 和 7z。
- 读取归档根目录及根目录下 `logs/` 中的日志。
- 跨文件搜索、字段过滤、命中高亮和上下文定位。
- 显示 Minecraft Java 的 `§` 颜色与格式化字符。
- 自动识别可能的编码，支持手动切换。
- 在同一窗口创建、编辑和另存日志副本。
